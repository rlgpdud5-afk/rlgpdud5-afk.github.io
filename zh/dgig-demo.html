D-GIG System Architecture

当前网站是 Phase 0 演示。Gig Match 与 LocalCrew 产生的完成记录会汇入同一个 Trust Graph，并扩展到 LER 签发层。

ENTRY 01 Gig Match

1–4 周短期岗位，按标签、地区与周期匹配，用于快速入门与地区试点验证。

ENTRY 02 LocalCrew / WBS

项目 → 模块 → 任务结构，Maker/Reviewer 评审，适用于 B2B、地方政府与大学项目。

OUTPUT Trust Graph → LER

将完成记录、评价、SLA 与 QA 汇总为信任分数，并转化为可验证的职业资产。

LER Credential Layers

LER 不是 v1 的前置条件，而是在信任数据积累后添加的升级层。长期结构采用 5 层验证，防止伪造、转让与虚假记录。

LAYER 1DID基于 worker DID 与私钥的身份绑定
LAYER 2W3C VC使用 Ed25519 签名签发工作记录
LAYER 3LER Mapping聚合 KR-LER-2025 技能代码与等级
LAYER 4Polygon Anchor仅将 SHA-256 哈希上链，不记录原文
LAYER 5ZKP Proof只证明经验条件，项目细节保持私密
VERIFY/verify/VRF-xxxx通过公开 URL 验证签名、哈希与状态
