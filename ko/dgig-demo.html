D-GIG System Architecture

현재 웹사이트는 Phase 0 데모이며, Gig Match와 LocalCrew에서 생성된 완료 기록을 하나의 Trust Graph로 모아 LER 발급 레이어로 확장합니다.

ENTRY 01 Gig Match

1~4주 단기 공고, 태그·지역·기간 매칭, 빠른 온보딩과 지역 파일럿 검증.

ENTRY 02 LocalCrew / WBS

프로젝트 → 모듈 → 태스크 구조, Maker/Reviewer 검수, B2B·지자체·대학 과업 수행.

OUTPUT Trust Graph → LER

완료 기록, 리뷰, SLA, QA를 신뢰 점수로 집계하고 검증 가능한 커리어 자산으로 전환.

LER Credential Layers

LER는 v1 필수 조건이 아니라 신뢰 데이터가 쌓인 뒤 붙는 업그레이드 레이어입니다. 장기 구조는 위변조·양도·허위기록을 차단하는 5계층 검증으로 설계합니다.

LAYER 1DIDworker DID와 개인키 기반 신원 바인딩
LAYER 2W3C VCEd25519 서명으로 업무 기록 발급
LAYER 3LER MappingKR-LER-2025 skill code와 level 집계
LAYER 4Polygon Anchor원문이 아닌 SHA-256 hash만 온체인 기록
LAYER 5ZKP Proof경력 조건만 증명하고 프로젝트 상세는 비공개
VERIFY/verify/VRF-xxxx서명 · 해시 · 상태를 공개 URL에서 검증
