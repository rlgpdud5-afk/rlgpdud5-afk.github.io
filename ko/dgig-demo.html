D-GIG 시스템 아키텍처

현재 웹사이트는 Phase 0 데모이며, Gig Match와 LocalCrew에서 생성된 완료 기록을 하나의 Trust Graph로 모아 LER 발급 레이어로 확장합니다.

진입점 01 Gig Match

1~4주 단기 공고, 태그·지역·기간 매칭, 빠른 온보딩과 지역 파일럿 검증.

진입점 02 LocalCrew / WBS

프로젝트 → 모듈 → 태스크 구조, Maker/Reviewer 검수, B2B·지자체·대학 과업 수행.

공통 산출물 Trust Graph → LER

완료 기록, 리뷰, SLA, QA를 신뢰 점수로 집계하고 검증 가능한 커리어 자산으로 전환.

제품 흐름 및 기술 스택

아키텍처는 정적 마케팅 사이트를 유지하면서, 앱 영역은 Vite + React + TypeScript, 데이터는 Supabase Postgres + Auth + RLS로 확장합니다.

LER 크레덴셜 검증 레이어

LER는 v1 필수 조건이 아니라 신뢰 데이터가 쌓인 뒤 붙는 업그레이드 레이어입니다. 장기 구조는 위변조·양도·허위기록을 차단하는 5계층 검증으로 설계합니다.

레이어 1DIDworker DID와 개인키 기반 신원 바인딩
레이어 2W3C VCEd25519 서명으로 업무 기록 발급
레이어 3LER MappingKR-LER-2025 skill code와 level 집계
레이어 4Polygon Anchor원문이 아닌 SHA-256 hash만 온체인 기록
레이어 5ZKP Proof경력 조건만 증명하고 프로젝트 상세는 비공개
검증/verify/VRF-xxxx서명 · 해시 · 상태를 공개 URL에서 검증

실시간 보안 이벤트 모니터링
